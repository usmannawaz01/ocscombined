# Old Church Slavonic Converter + Lemmatizer

## Overview
A GUI-based desktop tool for **converting** Old Church Slavonic (OCS) text and **lemmatizing** it using a dictionary of word–lemma pairs. Users can paste text, generate converted + lemmatized output, and explore results through an easy-to-use interface.

## Features
* **Text Conversion**
  *Converts OCS text into the target/standardized form using built-in conversion rules/mapping.*
* **Text Lemmatization**
  *Assigns the most frequent lemma to each word using a curated word–lemma dictionary.*
* **Word–Lemma Table**
  *Displays word–lemma mappings in a clear tabular format.*
* **Dataset Viewer**
  *Browse and view dataset files used by the tool.*
* **Interactive GUI**
  *Built with tkinter for simple and fast usage.*
